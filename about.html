About MyCraftingAI

The AI workshop for Minecraft modders.

MyCraftingAI is a Windows desktop application and AI-powered assistant for Minecraft Java Edition mod development. It writes the Java, paints the textures, builds the 3D models, converts mods between loaders and versions, and starts Minecraft with your mod loaded - all on real project files in your own folders.

What is MyCraftingAI?

A complete mod studio, driven by plain English.

MyCraftingAI is an advanced desktop application for Minecraft modders. You describe what you want - "a ruby ore between Y -16 and 32 that drops one or two rubies", "a dragon that flaps its wings while flying" - and the app turns it into working mod code and assets for Forge, NeoForge or Fabric, with GeckoLib added automatically when your mod uses animated 3D entities.

It is built around real Minecraft development: projects start from the official MDK and example-mod templates and are renamed to your mod (smart project scaffolding), code is compiled with Gradle, and the right Java version is picked or downloaded for you. When a build fails, the compiler errors go straight back to the AI, which fixes the code - and the app tells setup problems (wrong Java, no internet) apart from code problems, so tokens are never spent "fixing" code that is fine.

Beyond writing code, MyCraftingAI includes a 3D Studio for GeckoLib models and animations, a Texture Studio with a pixel-art AI, and a Version Converter that ports existing mods across loaders and Minecraft versions - from classics such as 1.12.2 and 1.16.5 up to 1.21.1 and newer - saving each result as a ready-to-build ZIP.

Core features

Six workspaces, one project.

Every workspace works on the same project folder, so you can switch between them - or open the files in any other editor - at any time.

Mod Assistant (chat)

All plans

Chat with an AI that reads your project before it writes. Each answer lists the files it created or changed, so you can review, undo or build straight away.

  • Items, blocks, ores, tools, armour, mobs, recipes, loot and world generation
  • Version-aware: uses the exact APIs of your loader and Minecraft version
  • Attach screenshots or reference images

3D Studio

Studio plan

Describe a mob and how it moves. The AI builds a GeckoLib model with bones, pivots and animations; watch every animation play in the app, then connect it to your code with one click.

  • GeckoLib release matched to your loader and version automatically
  • Walk, idle, attack and fly animations from a sentence
  • Paint textures directly on the model's UV layout

Texture Studio

Builder and up

Paint item, block and entity textures by hand, or describe them to the pixel-art AI. Turn the result in 3D to check it from every side.

  • 16x16 to 64x64 pixel art at the size the game expects
  • Palette, grid, zoom and undo
  • Mobs shown on their real 3D model

Version Converter

Studio plan

Point it at a mod folder: it detects the loader and Minecraft version, ports the mod to every loader and version you pick, and saves each one as a ready-to-build ZIP with a conversion report.

  • From Forge, NeoForge, Fabric and Quilt mods of any version
  • To Forge 1.7.10+, NeoForge 1.20.1+ and Fabric 1.14+ - e.g. 1.12.2 or 1.16.5 to 1.21.1
  • Predictable token estimate before it starts; optional compile check

Project Manager

All plans

Create a new mod or open an existing one. The start screen downloads the official template for the loader and version you choose and renames it to your mod, then the overview and code editor keep the whole project in view.

  • Smart scaffolding: com.my_mod, never com.example
  • Project overview with loader, version and Java detection
  • Files & Code editor with tabs, syntax colours and a project tree

Build & Run

All plans

Compile with Gradle and launch the Minecraft development client in one click. Failed builds go back to the assistant to fix, as many rounds as you allow, and a load check confirms the game really starts with your mod.

  • Right Java (8, 17, 21 or 25) chosen or downloaded automatically
  • Setup problems explained instead of sent to the AI
  • Live build and game log

Technology stack

Native desktop app, secure AI gateway.

MyCraftingAI runs on your PC and works on ordinary project folders. Only AI requests leave your computer, through our own gateway.

Python & PyQtA native Windows desktop app built with Python and the Qt framework (PyQt6), including live 3D model and animation previews.
GradleBuilds use each project's own Gradle wrapper - exactly how the loader's official tools build the mod.
Java 21 / 25 integrationDetects installed JDKs and picks the one each build needs - Java 21 for current Minecraft, Java 25 for the newest build tools, 8 and 17 for older versions - downloading it when missing.
AI gatewayDeepSeek models behind an OpenAI-compatible gateway run by MyCraftingAI. Provider keys stay on our servers and are never shipped in the app.
Version profilesLoader- and version-specific rules (1.12 to 1.21+) keep the AI on the right APIs, mappings and data formats.
Your files stay yoursCode, textures and models are written to your project folder. Backups of changed files are kept inside the project.
